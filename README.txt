RADBY SONDS — SITE PARA GITHUB PAGES

CONTEÚDO
- index.html: página inicial
- privacy.html: política de privacidade
- terms.html: termos de serviço
- assets/: identidade visual e CSS

PUBLICAÇÃO
1. Extraia este ZIP no computador.
2. Abra seu repositório GitHub (ex.: radby-sonds-site).
3. Clique em Add file > Upload files.
4. Envie os ARQUIVOS E PASTAS de dentro desta pasta extraída, não o ZIP.
   index.html precisa ficar na raiz do repositório.
5. Faça Commit changes.
6. No GitHub, abra Settings > Pages.
7. Em Build and deployment, selecione Deploy from a branch.
8. Branch: main; pasta: /(root); clique Save.
9. Aguarde a publicação. O endereço será https://SEU-USUARIO.github.io/radby-sonds-site/

ANTES DE USAR NO GOOGLE OAUTH
- Abra as páginas publicadas e confira se carregam.
- Revise a Política de Privacidade para refletir exatamente o comportamento real do APK.
- Confirme que o endereço de contato é monitorado.
- GitHub Pages fornece hospedagem, mas o domínio github.io compartilhado não garante, por si só, aprovação de domínio na verificação OAuth do Google. O Google pode exigir domínio próprio verificado no Search Console.
- Não declare recursos, práticas de segurança ou exclusão de dados que o aplicativo não implemente.
